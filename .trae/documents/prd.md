## 1. 产品概述

公众号写作神器是一款 AI Agent 驱动的一站式内容创作工具，面向微信公众号、头条等新媒体平台的内容创作者。用户输入主题后，AI 自动完成：风格化正文写作 → 智能标题摘要生成 → AI 封面图生成，实现从灵感到成品的完整创作闭环。

- 解决创作者在写作、起标题、做封面之间反复切换工具的低效问题
- 目标用户：公众号运营者、自媒体作者、内容营销人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 配置自有 API Key 后使用全部功能 |

### 2.2 功能模块

1. **创作工作台**：主题输入、风格选择、正文生成、标题摘要生成、封面图生成
2. **API 设置**：文本模型与图片模型独立配置，密钥本地存储

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 创作工作台 | 主题输入区 | 输入文章主题/大纲，选择写作风格 |
| 创作工作台 | 正文生成区 | SSE 流式生成正文，Markdown 渲染，一键复制 |
| 创作工作台 | 标题摘要区 | 批量生成 5 组标题+摘要，逐条复制 |
| 创作工作台 | 封面图区 | 生成 3 个 Prompt，选择后调用文生图模型出图，下载封面 |
| API 设置弹窗 | 文本模型配置 | API URL、API Key、模型名称 |
| API 设置弹窗 | 图片模型配置 | API URL、API Key、模型名称 |

## 3. 核心流程

用户打开页面 → 首次使用弹出 API 设置 → 输入主题并选择风格 → 点击生成正文（SSE 流式输出） → 正文完成后生成标题摘要（5组） → 生成封面 Prompt（3个） → 选择 Prompt 生成封面图 → 复制文本/下载图片

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝 (#4f46e5) + 翡翠绿 (#10b981) 点缀，暗色系为主
- **按钮风格**：圆角 (rounded-xl)，主按钮实色填充，次按钮描边
- **字体**：中文使用系统字体栈，英文/数字使用 JetBrains Mono 等等宽字体作为点缀
- **布局风格**：单页纵向流式布局，卡片式内容区块，顶部固定导航
- **图标**：Lucide React 图标库
- **动效**：卡片渐入动画、流式打字机效果、按钮 hover 微交互

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 创作工作台 | 顶部导航 | Logo + 设置按钮，毛玻璃背景，固定定位 |
| 创作工作台 | Hero 区 | 深色渐变背景，标语 + CTA 按钮，装饰光晕 |
| 创作工作台 | 主题输入区 | 白色卡片，textarea + 风格下拉 + 生成按钮 |
| 创作工作台 | 正文区 | 白色卡片，Markdown 渲染，复制按钮，风格标签 |
| 创作工作台 | 标题摘要区 | 白色卡片，5 组标题摘要列表，逐条复制 |
| 创作工作台 | 封面图区 | 白色卡片，关键点标签，3 个 Prompt 卡片，图片预览 + 下载 |
| API 设置弹窗 | 模态框 | 居中弹窗，文本/图片模型分区配置，保存/取消按钮 |

### 4.3 响应式设计

- 桌面优先设计，最大宽度 6xl 居中
- 移动端自适应：单列布局，按钮全宽，导航简化
- 触摸优化：按钮最小点击区域 44px
